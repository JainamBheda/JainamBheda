## 👨‍💻 About Me

🎓 Engineering graduate in Electronics & Telecommunication with Honors in AI & ML from DJSCE, Mumbai.

💼 Former Software Developer at **Veefin Solutions**, working on enterprise FinTech applications and banking integrations.

🚀 Interested in designing and developing scalable backend systems using Java and Spring Boot.

- Developed and worked on **Java 21 & Spring Boot** based backend services.
- Worked on **5 banking and NBFC integrations** in Supply Chain Finance.
- Experience with REST APIs, Hibernate, JPA, MySQL and Kafka.
- Explored AI-powered development using Spring AI and Model Context Protocol (MCP).
- Solved **500+ problems on LeetCode**.
- Continuously learning system design, backend architecture and distributed systems.

💡 I enjoy understanding how systems work, solving engineering problems and turning ideas into working software.
